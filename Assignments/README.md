---

## 🏆 Workflow & Submission Guidelines 📥

1. **Create Your Working Branch** 🌿:
   ```bash
   git checkout -b feature/assignment-<id>-<your-name>
   ```
2. **Follow The Directory Convention** 📁:
   ```text
   Assignments/
   └── <AssignmentID>-<Topic>/
       ├── solution/         # 💻 Code and scripts
       ├── docs/             # 📑 Design document or architecture diagrams
       └── README.md         # 📖 Overview, setup instructions & test results
   ```
3. **Commit Cleanly & Verify** ✅:
   - Ensure all secrets, credentials, and API keys are stored in `.env` (never commit secrets! 🔒).
   - Provide clear reproduction steps and test verification commands 🧪.
4. **Submit for Review** 🚀:
   - Open a Pull Request (PR) against the `main` branch with a summary of your solution.
